# Установка профиля

1. Создай публичный репозиторий с именем, совпадающим с твоим GitHub-ником.
2. Загрузи содержимое архива целиком, включая `.github/workflows`, `scripts` и `assets`. Не загружай сам ZIP вместо файлов.
3. В `README.md` и `README.en.md` замени `YOUR_USERNAME` и `YOUR_EMAIL`.
4. Открой **Actions → Update profile statistics → Run workflow**, если первое обновление ещё не запустилось. Дальше статистика обновляется ежедневно. Владелец профиля определяется автоматически через `GITHUB_REPOSITORY_OWNER`.

Главная версия — `README.md` на русском. Ссылки **Русский / English** сверху и снизу открывают нужную версию. Переключение работает обычными ссылками GitHub.

Баннер уже готов и анимирован. Статистика до первого запуска показывает честное состояние ожидания; выдуманных значений в комплекте нет.

## Статистика

Скрипт использует GitHub GraphQL API и автоматически предоставляемый `GITHUB_TOKEN`. Создавать персональный токен или передавать его сторонним сервисам не нужно. Workflow запрашивает `contents: write`, чтобы сохранять SVG в этом же репозитории. Политики организации и защита ветки могут ограничить автоматические коммиты — при ошибке смотри журнал Actions.

Карточки: публичные репозитории, звёзды собственных репозиториев без форков, коммиты и contributions за последний год. Календарь использует данные GitHub, а не случайно сгенерированные числа. Языки считаются по размеру кода в собственных публичных репозиториях без форков; закрытые репозитории скрипт не запрашивает. В суммарном календаре GitHub могут присутствовать обезличенные закрытые contributions, если ты включил их показ в профиле.

Статистика и баннер хранятся в репозитории. Только бейджи технологий загружаются с Shields.io.

## Редактирование

- Текст можно редактировать прямо в двух Markdown-файлах.
- `scripts/build_readmes.py` пересобирает обе версии из одного источника. Если пользуешься им, меняй контакты и тексты также в генераторе — иначе ручные изменения README будут перезаписаны.
- `assets/build_banner.py` пересоздаёт анимированный баннер; требуется Pillow (`python -m pip install Pillow`).
- `scripts/update_stats.py` использует только стандартную библиотеку Python.

Документация API: [GitHub GraphQL](https://docs.github.com/en/graphql), [автоматическая аутентификация Actions](https://docs.github.com/en/actions/security-for-github-actions/security-guides/automatic-token-authentication).
